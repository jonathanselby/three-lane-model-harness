THREE-LANE MODEL HARNESS — V0.2
===============================

Purpose
-------

V0.1 proved the routing pattern with mock + Ollama.
V0.2 proves the same caller/router contract across local and managed enterprise AI platforms.

The caller classifies. The harness routes.

Provider boundary
-----------------

                    +-----------------------+
                    |      ROUTER           |
                    +-----------+-----------+
                                |
                                | Provider.Generate(ctx, model, prompt)
                                v
                    +-----------------------+
                    |   PROVIDER CONTRACT   |
                    +-----------+-----------+
                                |
             +------------------+------------------+
             |                  |                  |
             v                  v                  v
       provider-specific  provider-specific  provider-specific
       endpoint/auth      request schema      response schema

The router does not know whether a request is local, Azure, AWS or GCP.
Provider-specific transport remains behind one stable interface.

Credential boundary
-------------------

Secrets are not command-line flags.

AZURE_OPENAI_API_KEY / AZURE_OPENAI_BEARER_TOKEN
AWS_BEARER_TOKEN_BEDROCK
GOOGLE_OAUTH_ACCESS_TOKEN
             |
             | environment
             v
      provider adapter only
             |
             v
      managed cloud endpoint

Credential acquisition, refresh, workload identity and secret storage remain
outside the harness and belong to the deployment environment.


Request flow
------------

REQUEST
  |
  v
VALIDATE TASK
  |
  +-- empty --------------------> FAILED TRACE
  |
  v
MAP COMPLEXITY TO LANE
  |
  +-- invalid ------------------> FAILED TRACE
  |
  v
VALIDATE PROVIDER + MODEL
  |
  +-- incomplete ---------------> FAILED TRACE
  |
  v
LOOK UP PROVIDER
  |
  +-- missing ------------------> FAILED TRACE
  |
  v
PROVIDER.GENERATE(ctx, model, task)
  |
  +-- configuration/auth error -> FAILED TRACE
  +-- HTTP error / timeout -----> FAILED TRACE
  +-- malformed response -------> FAILED TRACE
  |
  v
OUTPUT + TOKEN COUNTS + SUCCESS TRACE


Boundary
--------

Sensitive=true remains metadata only.

V0.2 does not implement classification, security enforcement, prompt filtering,
credential lifecycle, retry/failover, autonomous model selection or agent orchestration.
